# 使用说明（公开版）

## 本地演示

```powershell
python -X utf8 -m app --reset --port 8000
```

启动后访问 `http://127.0.0.1:8000/`。`--reset` 只用于本地演示，会重建演示库；演示账号和密码以启动输出为准。

## 公网访问

- 门户：`https://www.2026hfutintegratedcircuit1.com/`
- DDL：`https://www.2026hfutintegratedcircuit1.com/daliy/`
- 个人中心：`https://www.2026hfutintegratedcircuit1.com/personalcenter/`

真实班级的账号、密码、数据库与部署凭据不随仓库分发。

## 账号与权限

- 账号由班委创建；首次登录后需修改初始密码。
- 普通同学、班长/团支书、系统管理员按角色显示不同入口；跨班数据不可见。
- 个人中心与 DDL 共用一套账号体系；DDL 顶栏「个人中心」直接打开独立个人中心。

## PWA 安装与离线

- 桌面 Chrome/Edge：地址栏安装图标，或浏览器菜单「安装应用」。
- Android：Chrome 菜单「添加到主屏幕 / 安装应用」。
- iOS：Safari 分享菜单「添加到主屏幕」。
- 离线仅对**曾经在线加载过**的页面/数据生效；个人待办可离线编辑，联网后自动同步。
- 退出登录会清理本地缓存；共享电脑上请务必退出。

## 数据与备份

- 班级库：`data/classes/<slug>/classhub.db`（一班一库）。
- 新闻缓存：`data/portal.db`。
- 会话加密密钥：`data/.secret`，权限应为 0600。
- 备份必须同时包含班库、`portal.db` 与 `.secret`；恢复前先停服务。

## 原生客户端

- Android：`release/ClassHub-android-debug.apk`，debug 签名，仅供测试安装。
- Windows：`release/ClassHub-Setup-1.0.0.exe`，未签名；安装时可能出现 SmartScreen 提示。
- 客户端只是同一 HTTPS 站点的 WebView/Electron 壳，不包含独立数据库。

## 安全提示

不要把真实数据库、账号清单、`.secret`、机器人 Token、SSH/面板凭据提交到公开仓库或群文件。发现泄露时应立即更换密码、轮换密钥并清理备份。
