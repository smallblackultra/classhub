## 自查中发现并已修正的问题

1. 目录页码原为 `00` 占位；根据 PDF 书签目标页回填，并在改版后重新逐项核对。
2. 目录原跨两页且第二页留白过多；压缩行距与字号后改为单页。
3. 图 1、图 2 原有图片内嵌图题，与文档图题重复；裁掉内嵌图题后仅保留文档图题。
4. PDF 元数据与书签原为乱码；导出后用 Unicode 重写元数据与书签。
5. 改版引起分页变化；重新提取书签目标页，更新目录页码后再次导出。

## 复核命令

- DOCX 转 PDF：LibreOffice Kit `convert`
- PDF 页数与书签：pypdf 读取 `PdfReader.outline` 与 `get_destination_page_number`
- 页面渲染：LibreOffice Kit `render`，检查封面、目录、正文、图表、附录
- 敏感信息：DOCX 文本扫描姓名、学号、IP、凭据、初始密码等关键字
