# 数据模型与接口契约 v0.1

> 配套 `01-设计总览.md`。这份文档是前后端之间的合同：表结构、REST 接口、错误码、权限校验点。
> 实现可以换语言，但只要契约不变，前端/后端可以各自替换。

---

## 1. 约定

### 1.1 时间

- **存储**：一律 UTC，ISO8601 带 `Z`，秒级精度，字符串形式（SQLite 无原生时间类型，字符串可直接排序比较）。
- **传输**：同上。
- **展示**：前端统一按 `Asia/Shanghai` 渲染。
- **无明确时间的截止日**：`due_at` 存当天 `23:59:59 +08:00` 对应的 UTC，同时 `all_day=1`。
- **完全待定**：`due_at` 允许 `null`，前端显示"待定"，排序排最后。

### 1.2 字段命名

- JSON 一律 `snake_case`，与表字段同名，减少映射层。
- 枚举值一律小写英文，见各表。
- 布尔用 `0/1`。

### 1.3 错误格式

```json
{ "error": { "code": "forbidden", "message": "无权查看该条目" } }
```

| HTTP | code | 场景 |
|---|---|---|
| 400 | `invalid_request` | 参数缺失/格式错 |
| 401 | `unauthenticated` | 未登录或会话过期 |
| 403 | `forbidden` | 已登录但无权限 |
| 404 | `not_found` | 资源不存在**或不可见**（不泄露存在性） |
| 409 | `conflict` | 学号已注册、重复提交 |
| 422 | `rule_violation` | 业务规则不满足（如截止时间早于创建时间） |
| 429 | `rate_limited` | 登录/抽取限流 |

## 2. 表结构（SQLite DDL）

> 生产可直接用；迁移到 Postgres 时只需把 `INTEGER PRIMARY KEY AUTOINCREMENT` 换成 `BIGSERIAL`，`TEXT` 换 `TIMESTAMPTZ`。

```sql
PRAGMA journal_mode = WAL;
PRAGMA foreign_keys = ON;

CREATE TABLE classes (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  name         TEXT NOT NULL,                 -- 计算机 2301
  college      TEXT NOT NULL DEFAULT '',
  major        TEXT NOT NULL DEFAULT '',
  grade        TEXT NOT NULL DEFAULT '',
  invite_code  TEXT NOT NULL UNIQUE,          -- 8 位随机串，可轮换
  created_at   TEXT NOT NULL
);

CREATE TABLE users (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  class_id      INTEGER NOT NULL REFERENCES classes(id),
  student_no    TEXT NOT NULL UNIQUE,         -- 学号，登录名
  name          TEXT NOT NULL,
  role          TEXT NOT NULL DEFAULT 'student'
                CHECK (role IN ('student','monitor','secretary','admin')),
  status        TEXT NOT NULL DEFAULT 'pending'
                CHECK (status IN ('pending','active','disabled')),
  password_hash TEXT NOT NULL,                -- scrypt$N$r$p$salt$hash
  created_at    TEXT NOT NULL,
  last_login_at TEXT
);
CREATE INDEX idx_users_class ON users(class_id, status);

CREATE TABLE deadlines (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  class_id      INTEGER NOT NULL REFERENCES classes(id),
  title         TEXT NOT NULL,
  summary       TEXT NOT NULL DEFAULT '',
  category      TEXT NOT NULL
                CHECK (category IN ('homework','form','task','exam')),
  audience      TEXT NOT NULL DEFAULT 'class'
                CHECK (audience IN ('class','committee')),
  course        TEXT NOT NULL DEFAULT '',
  due_at        TEXT,                          -- UTC ISO8601，可空
  due_at_raw    TEXT NOT NULL DEFAULT '',      -- 原文写法
  all_day       INTEGER NOT NULL DEFAULT 0,
  location      TEXT NOT NULL DEFAULT '',
  link          TEXT NOT NULL DEFAULT '',
  attachments   TEXT NOT NULL DEFAULT '[]',    -- JSON 数组
  source_type   TEXT NOT NULL DEFAULT 'manual'
                CHECK (source_type IN ('manual','qq','paste','bookmarklet','chaoxing','yuketang','import')),
  source_ref    TEXT NOT NULL DEFAULT '',
  status        TEXT NOT NULL DEFAULT 'draft'
                CHECK (status IN ('draft','published','archived')),
  confidence    REAL,
  needs_review  INTEGER NOT NULL DEFAULT 0,
  dedupe_key    TEXT,
  created_by    INTEGER REFERENCES users(id),
  reviewed_by   INTEGER REFERENCES users(id),
  published_at  TEXT,
  created_at    TEXT NOT NULL,
  updated_at    TEXT NOT NULL
);
CREATE INDEX idx_dl_class_due    ON deadlines(class_id, status, due_at);
CREATE INDEX idx_dl_class_aud    ON deadlines(class_id, audience, status, due_at);
CREATE INDEX idx_dl_dedupe       ON deadlines(class_id, dedupe_key);

CREATE TABLE completions (
  deadline_id INTEGER NOT NULL REFERENCES deadlines(id) ON DELETE CASCADE,
  user_id     INTEGER NOT NULL REFERENCES users(id),
  state       TEXT NOT NULL DEFAULT 'done' CHECK (state IN ('done','skip')),
  note        TEXT NOT NULL DEFAULT '',
  updated_at  TEXT NOT NULL,
  PRIMARY KEY (deadline_id, user_id)
);

CREATE TABLE sources (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  class_id    INTEGER NOT NULL REFERENCES classes(id),
  type        TEXT NOT NULL,                   -- qq_onebot / bookmarklet / paste / chaoxing
  name        TEXT NOT NULL DEFAULT '',
  config      TEXT NOT NULL DEFAULT '{}',      -- 脱敏后配置
  enabled     INTEGER NOT NULL DEFAULT 1,
  token_hash  TEXT,                            -- 设备/机器人接入令牌的哈希
  last_ok_at  TEXT,
  last_error  TEXT,
  created_at  TEXT NOT NULL
);

CREATE TABLE raw_messages (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  source_id     INTEGER NOT NULL REFERENCES sources(id),
  external_id   TEXT,                          -- 平台侧消息 ID，用于幂等
  sender_name   TEXT NOT NULL DEFAULT '',
  sender_id     TEXT NOT NULL DEFAULT '',
  chat_name     TEXT NOT NULL DEFAULT '',
  content       TEXT NOT NULL,
  attachments   TEXT NOT NULL DEFAULT '[]',
  occurred_at   TEXT NOT NULL,
  ingested_at   TEXT NOT NULL,
  status        TEXT NOT NULL DEFAULT 'new'
                CHECK (status IN ('new','extracted','ignored','failed')),
  UNIQUE (source_id, external_id)
);
CREATE INDEX idx_raw_status ON raw_messages(status, ingested_at);

CREATE TABLE extraction_jobs (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  raw_message_id  INTEGER REFERENCES raw_messages(id),
  provider        TEXT NOT NULL,               -- deepseek / rules / mock
  model           TEXT NOT NULL DEFAULT '',
  prompt_version  TEXT NOT NULL DEFAULT 'v1',
  output          TEXT NOT NULL DEFAULT '',    -- 模型原始输出
  parsed          TEXT NOT NULL DEFAULT '{}',
  confidence      REAL,
  status          TEXT NOT NULL DEFAULT 'ok' CHECK (status IN ('ok','failed','invalid')),
  error           TEXT NOT NULL DEFAULT '',
  human_fix       TEXT NOT NULL DEFAULT '{}',  -- 班委修正的字段（评测样本）
  created_at      TEXT NOT NULL
);

CREATE TABLE revisions (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  deadline_id INTEGER NOT NULL REFERENCES deadlines(id) ON DELETE CASCADE,
  actor_id    INTEGER REFERENCES users(id),
  action      TEXT NOT NULL,                   -- create / update / publish / archive / delete
  before      TEXT NOT NULL DEFAULT '{}',
  after       TEXT NOT NULL DEFAULT '{}',
  created_at  TEXT NOT NULL
);

CREATE TABLE notifications (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id     INTEGER NOT NULL REFERENCES users(id),
  deadline_id INTEGER REFERENCES deadlines(id) ON DELETE CASCADE,
  channel     TEXT NOT NULL DEFAULT 'web',
  kind        TEXT NOT NULL,                   -- created / due_24h / due_3h / digest
  scheduled_at TEXT NOT NULL,
  sent_at     TEXT,
  status      TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending','sent','failed','skipped')),
  UNIQUE (user_id, deadline_id, kind, channel)
);

CREATE TABLE sessions (
  id         TEXT PRIMARY KEY,                 -- 随机 32 字节 hex
  user_id    INTEGER NOT NULL REFERENCES users(id),
  created_at TEXT NOT NULL,
  expires_at TEXT NOT NULL,
  ua         TEXT NOT NULL DEFAULT '',
  ip         TEXT NOT NULL DEFAULT ''
);

CREATE TABLE audit_logs (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  actor_id   INTEGER,
  action     TEXT NOT NULL,
  target     TEXT NOT NULL DEFAULT '',
  meta       TEXT NOT NULL DEFAULT '{}',
  ip         TEXT NOT NULL DEFAULT '',
  created_at TEXT NOT NULL
);

CREATE TABLE settings (
  key        TEXT PRIMARY KEY,
  value      TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
```

## 3. REST 接口

统一前缀 `/api`。除标注外均需登录。请求体 `Content-Type: application/json`。

### 3.1 认证

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/auth/register` | `{student_no, name, password, invite_code}` → 创建 `pending` 用户。学号重复 409，邀请码错 422 |
| POST | `/auth/login` | `{student_no, password}` → `Set-Cookie: sid=...; HttpOnly; SameSite=Lax` |
| POST | `/auth/logout` | 删除会话 |
| GET | `/auth/me` | 返回当前用户 + 班级 + 未读草稿数 |

`pending` 用户可登录但只能看到"等待班委审批"页面，所有业务接口返回 403 `pending_approval`。

### 3.2 条目

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/deadlines` | 登录 | 查询参数见下 |
| POST | `/deadlines` | 班委 | 手动新建，默认直接 `published`（除非 `as_draft=true`） |
| GET | `/deadlines/{id}` | 可见者 | 详情 |
| PATCH | `/deadlines/{id}` | 班委 | 局部更新，写 revisions |
| DELETE | `/deadlines/{id}` | 班委 | 软删（`archived` + `deleted` 标记放 revisions） |
| POST | `/deadlines/{id}/publish` | 班委 | `draft → published` |
| POST | `/deadlines/{id}/archive` | 班委 | `→ archived` |
| POST | `/deadlines/{id}/complete` | 登录 | `{state: "done"｜"skip"｜"pending"}` 仅本人 |
| GET | `/deadlines/{id}/completions` | 班委 | 已填/未填名单（仅 form/task） |

**GET /deadlines 查询参数**

| 参数 | 值 | 默认 | 说明 |
|---|---|---|---|
| `status` | `published｜draft｜archived｜all` | `published` | 同学传 `draft` 直接 403 |
| `category` | 类别，逗号分隔 | 全部 | |
| `audience` | `class｜committee` | 按角色 | 同学固定 `class`，传 `committee` 无效果 |
| `q` | 关键词 | — | 标题/课程/摘要 LIKE |
| `from` / `to` | 日期 | — | 按 `due_at` 过滤，日历用 |
| `sort` | `due｜created` | `due` | `due_at IS NULL` 永远排最后 |

**响应**

```json
{
  "items": [{
    "id": 12, "title": "第 5 章实验报告", "category": "homework",
    "audience": "class", "course": "操作系统",
    "due_at": "2026-11-11T15:59:00Z", "due_at_raw": "下周三前",
    "all_day": false, "status": "published",
    "source_type": "qq", "created_by_name": "张明",
    "my_completion": "done", "completion": { "done": 18, "total": 45 }
  }],
  "counts": { "today": 1, "week": 3, "overdue": 2, "drafts": 4 }
}
```

> `counts` 只统计**当前用户可见**的条目。`drafts` 仅班委有值，同学返回 0。

### 3.3 采集

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/ingest/paste` | 登录 | `{text, source_hint?}` → 建 raw_message → 同步抽取 → 返回 draft |
| POST | `/ingest/qq` | 机器人令牌 | `{token, group_id, group_name, sender_id, sender_name, msg_id, text, reply_text?, occurred_at}` |
| POST | `/ingest/bookmarklet` | 一次性令牌 | `{token, platform, page_url, items:[{title, course, due_text}]}` |
| GET | `/ingest/queue` | 班委 | 未解析/失败的原始消息列表 |
| POST | `/ingest/queue/{id}/retry` | 班委 | 重跑抽取 |
| POST | `/ingest/queue/{id}/manual` | 班委 | 用原文手动建草稿 |

机器人令牌：admin 在管理端生成，形如 `qq_<classId>_<32hex>`，服务端只存 `sha256`。

### 3.4 草稿审核

草稿就是 `status=draft` 的 `deadlines`，不另建表。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/drafts` | 班委，返回草稿 + 关联的原文（联查 raw_messages） |
| POST | `/drafts/{id}/publish` | 同 `/deadlines/{id}/publish` |
| POST | `/drafts/{id}/reject` | `{reason}` → 标记 archived + 记录 |

### 3.5 管理

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/admin/users` | 列表，含 pending |
| PATCH | `/admin/users/{id}` | `{role?, status?}` |
| POST | `/admin/invite/rotate` | 轮换邀请码 |
| GET | `/admin/sources` | 数据源状态 |
| POST | `/admin/sources` | 新建（返回一次性明文令牌） |
| GET | `/admin/stats` | 条目数、抽取成功率、最近消息时间 |
| GET | `/admin/audit` | 审计日志 |

### 3.6 元信息

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/meta` | 服务端时间、时区、类别枚举、当前用户可见的筛选项 |

## 4. 权限校验点（后端唯一实现）

```python
# domain/policy.py

def can_view(user, item):
    if user.status != "active":        return False
    if item.class_id != user.class_id: return False
    if item.status == "published":     return item.audience == "class" or is_committee(user)
    return is_committee(user)          # draft / archived 只有班委可见

def can_write(user, item=None):
    return user.status == "active" and is_committee(user) \
           and (item is None or item.class_id == user.class_id)

def can_review(user):
    return user.status == "active" and is_committee(user)

def is_committee(user):
    return user.role in ("monitor", "secretary", "admin")
```

**三个必须写测试的点**：

1. 同学访问 `audience=committee` 的条目 → 404（不是 403，避免探测）。
2. 同学请求 `status=draft` 列表 → 403。
3. 班委只能操作本班条目；跨班 `class_id` 一律 404。

## 5. 前端状态约定

- 登录态：`GET /auth/me` 成功后缓存到内存，刷新重取；401 统一跳登录。
- 列表刷新：发布/修改后不整页刷新，局部重取 `GET /deadlines`。
- 草稿角标：`me.pending_drafts`，操作后重取。
- 所有写请求带 `X-CSRF: <cookie csrf>` 双提交校验。

## 6. 与 01 文档的差异记录

- 01 §5.3 的"AI 不能自动发布"在接口层体现为：`/ingest/*` 只产出 `status=draft`，没有任何参数能直接产出 `published`。
- 01 §3.2 的 `deadlines.status` 增加 `archived` 作为软删/过期归档共用状态，删除即归档 + 审计。
