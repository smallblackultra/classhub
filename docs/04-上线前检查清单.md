1. **部署环境**：只在你自己电脑上给班里用（局域网），还是要一个公网/校内域名？有没有服务器？
2. **QQ 机器人**：有没有能常开的机器和一个 QQ 小号？学校对群机器人有没有限制？
3. **AI Key**：现在有没有 DeepSeek 或其他 OpenAI 兼容的 Key？没有的话先纯规则，够不够用？
4. **真实数据**：班级名称/学院/专业/年级、成员学号名单，什么时候能给？要不要我写一个「从 Excel 导入成员」的小脚本？
5. **通知渠道**：站内铃铛够不够？是否需要邮件/企业微信/QQ 群主动推送（需要额外凭证）？
6. **可见性细节**：有没有「只给某几个人看」的条目需求（比如助学金名单）？目前只有「全班 / 班委」两档。

## 已知边界（不是 bug，是取舍）

- 学习通/雨课堂**没有稳定的公开 API**，服务端全自动抓取不承诺；书签抓取 + 粘贴是可靠路径。
- 图片通知不做 OCR，只存原图链接/说明，需班委手动补录。
- 站内通知只在打开页面/轮询时出现，不推送系统通知（浏览器权限另说）。
- 单进程 SQLite，适合一个班（< 200 人）；多班建议一班一库。
- 密码找回、邮箱验证未做；忘记密码需管理员重置（当前需脚本，见 Q2）。
